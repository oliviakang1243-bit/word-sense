# WORD SENSE v0.5

Single-file HTML vocabulary learning web app.

## Deployment
Upload `index.html` and `.nojekyll` to the root of a GitHub repository named `word-sense`. In Settings > Pages choose Deploy from a branch, `main`, `/(root)`.

Site address after publishing: https://Arctictarzan.github.io/word-sense/

## Data and privacy
Learning records and vocabulary edits use browser localStorage; they do not sync across devices. The public website can be viewed by anyone with its URL. Some vocabulary source verification remains pending.
